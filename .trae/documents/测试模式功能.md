# 测试模式功能计划

## Summary

通过 URL 参数 `?test=1` 进入测试模式。页面顶部显示"测试模式"横幅，提交时答案自动标记为测试数据。管理员统计面板提供切换按钮，可自由选择是否过滤测试数据。

## Proposed Changes

### 改动文件
- `/workspace/survey.html`（唯一文件）

### 1. 检测测试模式

在 JS 常量区域，添加：
```javascript
const isTestMode = new URLSearchParams(window.location.search).get('test') === '1';
let filterTestData = true; // 管理员面板默认过滤测试数据
```

### 2. 页面顶部"测试模式"横幅

在 `<body>` 开头、header 之前，添加 HTML + CSS：
```html
<div id="testBanner" style="display:none;">⚠️ 当前为测试模式 — 提交的答案将标记为测试数据</div>
```
CSS：黄色背景，居中文字，醒目但不影响答题。JS 初始化时如果 `isTestMode` 为 true 则显示。

### 3. 提交时标记测试数据

`submitSurvey()` 的 entry 对象新增字段：
```javascript
isTest: isTestMode
```
同时 body 传参也加上 `isTest`。

### 4. 管理员统计面板加切换按钮

`renderStatsWithData(data)` 中，在 admin-actions 区域新增一个 toggle 按钮：
```html
<button class="btn-secondary" onclick="toggleTestFilter()">过滤测试数据：开/关</button>
```

`toggleTestFilter()` 切换 `filterTestData` 布尔值，然后重新调用 `renderStatsWithData(rawData)`。在函数开头根据 `filterTestData` 决定是否过滤：
```javascript
function renderStatsWithData(data) {
  // 保存原始数据供切换时重渲染
  window._rawStatsData = data;
  const testCount = data.filter(d => d.isTest).length;
  const displayData = filterTestData ? data.filter(d => !d.isTest) : data;
  // ...用 displayData 渲染
  // 头部显示："共 X 份有效回答（已排除 Y 份测试数据）" 或 "共 X 份（含测试数据）"
}
```

### 5. 报告页默认过滤测试数据

`renderReportWithData(data)` 默认过滤（硬编码，不加切换按钮）：
```javascript
const testCount = data.filter(d => d.isTest).length;
const displayData = data.filter(d => !d.isTest);
```
报告头部显示："有效样本 X 份（已排除 Y 份测试数据）"

### 6. 使用方式

| 用途 | 链接 | 效果 |
|------|------|------|
| 发给朋友 | `https://xxx.vercel.app/` | 正常模式，无标识 |
| 自己测试 | `https://xxx.vercel.app/?test=1` | 页面显示测试横幅，答案标记 isTest:true |

## Assumptions

- 不改后端，仅前端标记
- 管理员统计面板有切换按钮，默认过滤
- 报告页默认过滤，不提供切换（公开页面）
